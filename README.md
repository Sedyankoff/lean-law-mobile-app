# LeanLaw – Minimal Macro Tracker (React Native + SQLite)

## Идея

LeanLaw е минималистично мобилно приложение, което позволява проследяване на дневни хранителни цели – калории, протеин, въглехидрати и мазнини.  
Потребителят задава дневни цели и добавя храни с техните стойности.

Фокусът е върху простота, бързина и реална използваемост без излишни усложнения.

---

## Как работи

- Потребителят задава дневните цели (Calories, Protein, Carbs, Fats)
- На Today екрана вижда прогрес барове и списък с добавени храни
- CRUD операции:
  - добавяне на храна
  - редакция
  - изтриване
- Данните се съхраняват локално в SQLite база (persisted storage)
- Автоматично се изчисляват:
  - общи макроси за деня
  - оставащи макроси спрямо целите

---

## Интеграция на изкуствен интелект

Към приложението е добавена AI функционалност чрез Google Gemini API.

### Какво прави AI функционалността

Потребителят може да генерира предложения за хранене спрямо оставащите макроси за деня.

Входни към AI:

- оставащи калории
- оставащ протеин
- оставащи въглехидрати
- оставащи мазнини
- предпочитани храни (опционално)
- храни, които да се избягват (опционално)

Отговор от AI:

- 3 предложения за хранене
- списък със съставки
- приблизителни макроси
- кратко обяснение защо предложението е подходящо

### Архитектура на AI частта

AI интеграцията е реализирана чрез малък backend (proxy слой):

- Mobile App (Expo / React Native)
- Node.js / Express backend → /api/ai/macro-suggestions
- Google Gemini API

Причината:

- API ключът не се излага в мобилното приложение
- по-чиста архитектура
