# LeanLaw – Minimal Macro Tracker (React Native + SQLite)

## Идея

LeanLaw е минималистично мобилно приложение, което позволява проследяване на дневни хранителни цели – калории, протеин, въглехидрати и мазнини.  
Потребителят задава дневни цели и добавя храни с техните стойности.

## Как работи

- Потребителят задава дневните цели (Calories, Protein, Carbs, Fats).
- На Today екрана вижда прогрес барове и списък с добавени храни.
- CRUD: добавяне, редакция, изтриване на храни.
- Данните се съхраняват в SQLite база (persisted storage).
- Допълнителни функционалности:
  - Share Intent – споделяне на дневния прогрес.
  - QR Code генератор – генериране на код със статистиката.

## Архитектура

LeanLaw следва MVVM подход, опростен за мобилна работа:

- `screens/` – UI слоеве (View)
- `storage/` – Repository слой (SQLite)
- `services/` – бизнес логика (ViewModel-level функции)
- `components/` – UI компоненти (ProgressBar, FoodListItem)

SQLite се използва чрез `expo-sqlite` за локално съхранение на данни.

## Потребителски flow

1. Стартиране на приложението
2. Задаване на дневни цели (Targets tab)
3. Въвеждане на храни (Today tab)
4. Преглед на прогрес → progress bars
5. Share за изпращане на дневни резултати или QR code за визуално споделяне

## Setup / Run

### Изисквания:
- Node 18+
- Expo CLI
- Android device / emulator

### Инсталация:
```bash
npm install
npm start
```

### Стартиране на устройство:
- Инсталирайте Expo Go
- Сканирайте QR кода или използвайте USB debug

## Тестване

Тестовете покриват логиката (macroService) и UI workflow (Today screen).

```bash
npm test
```
